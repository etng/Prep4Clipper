# 隐私与权限

## 本地处理

Prep4Clipper 在浏览器内容脚本的隔离环境中运行，读取当前页面中符合条件的文章标题、标题元数据和 Urvanov / Crayon 代码块，并修改页面 DOM。原始代码块节点暂存于当前内容脚本内存中，供内部恢复逻辑使用，不写入磁盘；刷新或关闭页面后释放。

扩展自身不发送网络请求，不使用 CDN、统计、遥测、远程配置或账号服务。Prism 和图标均随扩展打包。扩展不读取 Obsidian 笔记，也不调用 Web Clipper 的内部接口；Web Clipper 读取的是整理后的页面。

## 权限用途

| 声明 | 用途 |
| --- | --- |
| `storage` | 在 `chrome.storage.local` 中保存一个 `theme` 配色选项；不使用浏览器账号同步存储。 |
| 内容脚本匹配 `http://*/*`、`https://*/*` | 在用户允许的网站上自动检测目标结构，无需手工点击。没有配置 `all_frames`，只处理主文档。 |

没有申请历史记录、Cookie、下载、剪贴板或笔记权限。浏览器仍可能对广泛的网页访问范围显示权限提示，这是自动处理网页所需的访问声明。

## 用户控制与边界

可以在浏览器扩展管理页限制允许访问的网站，或暂时禁用扩展；访问受限时对应页面不会自动整理。禁用后刷新页面即可恢复原始网页。卸载扩展会移除其本地设置。

整理后的代码和标题仍属于网页 DOM，网站自己的脚本及其他获准访问页面的扩展可能读取它们。网站本身和 Web Clipper 的网络或存储行为由各自的软件负责，本说明仅描述 Prep4Clipper。

提交 Issue 时请用虚构文章和代码复现问题，避免公开带登录信息的 URL、访问令牌、真实页面快照或私人笔记。
